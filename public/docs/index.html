Introduction

REST API для приложения задач: команды с ролями, проекты, задачи, комментарии и метки.

Base URL: https://damp-violet-4757.mkeyboard138.workers.dev 
Бэкенд для мобильного или веб-клиента таск-менеджера. Все ответы — JSON.

## Формат ответов

Успешный ответ оборачивается в `data`. Списки постраничные: рядом лежат `links` и `meta` (`current_page`, `last_page`, `per_page`, `total`). Списки задач в v2 — курсорные: `meta` содержит `next_cursor` и `prev_cursor`.

Ошибки всегда имеют одинаковую форму:

```json
{ "message": "The title field is required.", "errors": { "title": ["The title field is required."] } }
```

| Код | Когда |
|---|---|
| 202 | Задача принята в фоновую обработку (выгрузка CSV) |
| 400 | Неизвестный фильтр или поле сортировки |
| 401 | Нет токена или он отозван |
| 403 | Вы в команде, но вашей роли не хватает прав |
| 404 | Ресурса нет **или он принадлежит команде, в которой вы не состоите** |
| 409 | Файл выгрузки ещё не готов |
| 422 | Ошибка валидации, поле `errors` содержит детали |
| 429 | Превышен лимит запросов |

## Версии API

Версия — часть адреса: `/api/v1/...`, `/api/v2/...`.

| Версия | Что входит |
|---|---|
| v1 | Все ресурсы: авторизация, профиль, команды, проекты, задачи, комментарии, метки, экспорт |
| v2 | Только задачи: курсорная пагинация, статус и приоритет объектами `{"value": "todo", "label": "To do"}`, автор задачи объектом `creator` вместо `creator_id` |

v2 содержит только ресурсы с несовместимыми изменениями. Всё остальное клиент v2 по-прежнему берёт из v1. Тела запросов и права доступа в обеих версиях одинаковые.

Эндпоинты задач в v1 устарели и в каждом ответе сообщают об этом заголовками:

| Заголовок | Пример | Смысл |
|---|---|---|
| `Deprecation` | `@1790208000` | С какой даты версия устарела (Unix-время, RFC 9745) |
| `Sunset` | `Wed, 31 Mar 2027 00:00:00 GMT` | Когда её планируется отключить (RFC 8594) |
| `Link` | `<https://.../api/v2/tasks/7>; rel="successor-version"` | Тот же ресурс в v2 |

## Роли в команде

| Действие | owner | admin | member |
|---|---|---|---|
| Смотреть команду, проекты, задачи | ✅ | ✅ | ✅ |
| Создавать и менять задачи, комментировать | ✅ | ✅ | ✅ |
| Удалять задачи | любые | любые | только свои |
| Управлять проектами, метками, участниками | ✅ | ✅ | ❌ |
| Удалить команду, передать владение | ✅ | ❌ | ❌ |

## Лимиты запросов

| Что | Лимит в минуту | Считается по |
|---|---|---|
| Все эндпоинты, с токеном | 120 | пользователю |
| Публичные эндпоинты (вход, регистрация) | 30 | IP |
| Вход | 5 | email + IP |
| Регистрация | 10 | IP |
| Приглашения | 20 | пользователю |
| Запуск выгрузки | 5 | пользователю |

В каждом ответе есть заголовки `X-RateLimit-Limit` и `X-RateLimit-Remaining`, при превышении — `429` и `Retry-After` (секунды до сброса).

## Кэш

Роли в командах и статистика проектов кэшируются в Redis. Кэш сбрасывается сразу при изменении данных, поэтому ответы всегда актуальны.

Authenticating requests

To authenticate requests, include an Authorization header with the value "Bearer {YOUR_TOKEN}".

All authenticated endpoints are marked with a requires authentication badge in the documentation below.

Токен выдают POST /api/v1/auth/register и POST /api/v1/auth/login. Передавайте его в заголовке Authorization: Bearer {token}.

Авторизация

Регистрация, вход и выход. Токен передаётся в заголовке Authorization: Bearer {token}.

Регистрация

Создаёт пользователя и сразу возвращает токен доступа.

Example request:
curl --request POST \
    "https://damp-violet-4757.mkeyboard138.workers.dev/api/v1/auth/register" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json" \
    --data "{
    \"name\": \"Анна Смирнова\",
    \"email\": \"anna@example.com\",
    \"password\": \"secret-pass-123\",
    \"device_name\": \"iPhone 15\"
}"

const url = new URL(
    "https://damp-violet-4757.mkeyboard138.workers.dev/api/v1/auth/register"
);

const headers = {
    "Content-Type": "application/json",
    "Accept": "application/json",
};

let body = {
    "name": "Анна Смирнова",
    "email": "anna@example.com",
    "password": "secret-pass-123",
    "device_name": "iPhone 15"
};

fetch(url, {
    method: "POST",
    headers,
    body: JSON.stringify(body),
}).then(response => response.json());
