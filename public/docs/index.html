Introduction

REST API для приложения задач: команды с ролями, проекты, задачи, комментарии и метки.

Base URL: http://localhost:8000 
Бэкенд для мобильного или веб-клиента таск-менеджера. Все ответы — JSON.

## Формат ответов

Успешный ответ оборачивается в `data`. Списки постраничные: рядом лежат `links` и `meta` (`current_page`, `last_page`, `per_page`, `total`).

Ошибки всегда имеют одинаковую форму:

```json
{ "message": "The title field is required.", "errors": { "title": ["The title field is required."] } }
```

| Код | Когда |
|---|---|
| 400 | Неизвестный фильтр или поле сортировки |
| 401 | Нет токена или он отозван |
| 403 | Вы в команде, но вашей роли не хватает прав |
| 404 | Ресурса нет **или он принадлежит команде, в которой вы не состоите** |
| 422 | Ошибка валидации, поле `errors` содержит детали |
| 429 | Превышен лимит запросов |

## Роли в команде

| Действие | owner | admin | member |
|---|---|---|---|
| Смотреть команду, проекты, задачи | ✅ | ✅ | ✅ |
| Создавать и менять задачи, комментировать | ✅ | ✅ | ✅ |
| Удалять задачи | любые | любые | только свои |
| Управлять проектами, метками, участниками | ✅ | ✅ | ❌ |
| Удалить команду, передать владение | ✅ | ❌ | ❌ |

Authenticating requests

To authenticate requests, include an Authorization header with the value "Bearer {YOUR_TOKEN}".

All authenticated endpoints are marked with a requires authentication badge in the documentation below.

Токен выдают POST /api/v1/auth/register и POST /api/v1/auth/login. Передавайте его в заголовке Authorization: Bearer {token}.

Авторизация

Регистрация, вход и выход. Токен передаётся в заголовке Authorization: Bearer {token}.

Регистрация

Создаёт пользователя и сразу возвращает токен доступа.

Example request:
curl --request POST \
    "http://localhost:8000/api/v1/auth/register" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json" \
    --data "{
    \"name\": \"Анна Смирнова\",
    \"email\": \"anna@example.com\",
    \"password\": \"secret-pass-123\",
    \"device_name\": \"iPhone 15\"
}"

const url = new URL(
    "http://localhost:8000/api/v1/auth/register"
);

const headers = {
    "Content-Type": "application/json",
    "Accept": "application/json",
};

let body = {
    "name": "Анна Смирнова",
    "email": "anna@example.com",
    "password": "secret-pass-123",
    "device_name": "iPhone 15"
};

fetch(url, {
    method: "POST",
    headers,
    body: JSON.stringify(body),
}).then(response => response.json());

Команды

Команда объединяет людей и проекты. Роли в команде: owner (один), admin, member. Если вы не состоите в команде, её ресурсы отвечают 404.
